About this map

  • One course shows only what that course names and what names it. Whole map shows every connection at once, and its Core view starts with the most-connected undergraduate courses.
  • Connections come from each term's SPIRE prerequisite field, or the course description where SPIRE has no entry. Old numbers mentioned only as history, like "(previously INFO 190T)", don't get an arrow, and renumbered courses stay one box. Neither does a course the wording says isn't required, like "helpful but not required".
  • An arrow doesn't separate "requires" from "accepts as an option", so select a course to read its exact prerequisite wording.
  • A course that runs only in fall or spring stays on the map through the following term, so it doesn't flicker as the slider moves. Its arrows come from its most recent listing.
  • A dashed box is an experimental course, meaning its number has a letter. Courses with no connections aren't shown.
  • The Core view shows undergraduate courses that at least two regular courses, at any level, have named. Math below MATH 132 only appears as a placement option for intro courses, so it's shown only when Other departments is set to All.
  • COMPSCI 473 has no listing in these terms. It was an optional version of COMPSCI 373: students could take 373, or do an extra project and take 473. This note was added by hand and doesn't come from the CICS documents.
